# Bibash Pandey — Portfolio

Personal portfolio website showcasing my background, technical skills, selected projects, education, certifications, and interests.

## Focus

- AI / Machine Learning
- Data Science
- Generative AI
- RAG applications
- AI agents and tool calling

## Tech

This portfolio is built as a lightweight static website using:

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Structure

```text
.
├── index.html
├── script.js
├── style.css
└── assets/
    ├── icons/
    └── images/
```

## Navigation

The site uses section anchors for quick access to the main portfolio areas:

- About
- Skills
- Projects
- Education
- Contact

## Accessibility

The interface includes reduced-motion handling for users who prefer less animation, semantic form status messaging, and descriptive image/link labels.

## Contact Form

The contact form currently provides a client-side confirmation message. It does not send data to a backend service.

## Performance

The site uses lightweight vanilla JavaScript and loads only the libraries needed for typography and page interactions.

## Local Development

Open `index.html` directly in a browser, or serve the project with any simple static web server.
