# Deployment Notes

This portfolio is a static website and does not require a build step.

## Files

- `index.html` — page structure and content
- `style.css` — layout, typography, responsive styling, and animations
- `script.js` — scroll effects and contact-form interaction
- `assets/` — profile imagery and icons

## Deployment

The site can be hosted on GitHub Pages or any static hosting provider that serves HTML, CSS, JavaScript, and assets from the project directory.

Before publishing, verify that the CV, profile image, and icon paths resolve correctly and that external links open as expected.
